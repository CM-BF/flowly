Quick follow-up on **Flowly**, my Paseo plugin. Using it across several tasks has changed how I work with agents: I spend less time checking chats and more time deciding what needs to happen next.

For me, it’s **a workflow with a kanban board as its interface**. Agents report their own stages as they plan, implement, test and hand work back. **Needs you** shows where my input is needed, with context to help me make the call.

Three AI features make that loop easier:

- **Task summary:** When I return to a task, I can see its goal, progress and next step without rereading the conversation. It updates after completed turns.
- **Next moves:** When a turn finishes, the agent suggests concrete follow-ups, like verifying or committing changes. A tap fills in an editable instruction; I choose what to send.
- **Ideas:** When the agent discovers a useful improvement or another bug, it saves the suggestion with context and why it matters. I can continue in the same session or start a new task without rebuilding that context.

Since my last post, I’ve also added **Workpads** so I can review acceptance criteria and see what’s been tested; **Artifacts** to keep source material and deliverables with each task; and **external connectors, starting with Jira**, so agents can read the ticket context directly. There’s also been plenty of **UI/UX polish and performance improvements**, with cleaner card layouts, easier navigation and lighter background updates—especially for mobile use.

The benefit for me is less effort tracking work and picking it back up. When something needs my attention, I can get straight to the decision.
