# Flowly 1.7.0

Covers everything merged to `main` since v1.6.0 (#57–#67 and the Insights redesign). The in-app *What's new* window shows the highlights marked ★.

## New

- ★ **Insights redesign.** A year of activity as a heatmap; tap a day for its summary card, page day by day with the arrows (agent time, tokens and a bar per card). The Workflow section looks at the cards finished in the last 7 days: the attention each took, review rounds and one-pass share, where the time went (working, waiting for review or a reply, idle), tokens and agent time per card and per model, and 8 weeks against the project's own past. Insights no longer counts daily output.
- ★ **Skill drafts.** Workflow insights drafts skills from what agents keep redoing on your cards; a draft is added to the project (`SKILL.md`) only when you say so. On by default for everyone who never touched the switch; turn it off in Settings → AI features.
- ★ **Board in SQLite with daily backups.** Where Paseo supports it, the first start moves `board.json` into a local SQLite database after a verified snapshot. Settings → Storage shows where the board is kept, its daily backups (7 kept), restores one, and exports the board to a JSON file the previous release reads. (#64)
- ★ **Anonymous usage data.** Once a day: versions, which features are on and usage counts; on daemon errors, the error type and where in Flowly's own code. Never your content, paths or code. Turn it off in Settings → General, or with `DO_NOT_TRACK=1`. (#65, #66)
- ★ **Running sweep switch** in Settings → Cards. (#60)
- **Folded subagent rows sweep** while one of their subagents runs. (#58)

## Improved

- ★ **Faster loading.** Every layout reads the board overview and the open card's detail instead of the whole board; the biggest gain is on phones. (#67)
- ★ **Settings fill the screen on phones** instead of a floating window. (#60)
- **Plainer UI text.** Descriptions that only restated a title are gone from settings, the project form, Connections, Memory and the card sidebar; cost, privacy and side-effect notes stay. (#60)
- **What's new pages left and right.** The arrows beside the version page to older (left) and newer (right) releases.
- On web the running sweep and pulse dot run as CSS animations, so many running cards no longer load the JS thread. (#62)
- The sidebar attention badge refreshes at once on Mark as read and every 3 seconds. (b2e9c40)

## Fixed

- Queued messages no longer flicker while the session confirms them, and a sent message appears in the transcript right away. (#59)
- The running sweep restarts when its loop ends or the app returns to the foreground. (#57)
- Section titles stay on one line on narrow phones. (#63)
- The Ideas popover on a native session keeps its title and scrolls only the list. (0687ff0)

## Upgrade

Requires Paseo 0.11.2 or later. Existing project data and settings are preserved. The first start on a Paseo that supports SQLite moves the board into `flowly.sqlite`; `board.json` stays behind as a marker that older Flowly versions refuse, so to go back to 1.6 export the board first (Settings → Storage → Export to JSON). Usage data is on by default; see Settings → General.
