# Flowly 1.7.2

A patch for one bug, nothing else. No *What's new* page: nothing here changes how existing users work.

## Fixed

- **Cards stopped getting a Progress summary.** Since Paseo 0.13 the end-of-turn hook no longer carries the turn's conversation, so the summary never ran and gave no error. Flowly now reads the last turn from the session itself. The same empty input also kept these from working: the *Agent habits* "by you" and "took a suggestion" marks, the memory clues from your messages, the card's plan in the workpad, and insights for sessions Flowly does not manage. Turns that ended since Paseo 0.13 keep their old, wrong "by you" mark; Progress for them returns on the card's next turn or with *Refresh*.

## Upgrade

Requires Paseo 0.11.2 or later. Existing project data and settings are preserved.
