# Flowly 1.6.0

Covers everything merged to `main` since v1.5.0 (#20–#55). The in-app *What's new* window shows the highlights marked ★.

## New

- ★ **Project memory.** Decisions, conventions, pitfalls and contacts you confirm on one card carry over to the sessions of later cards in the same project. Agents propose entries with `flowly_remember` and you confirm them; when a card reaches Done, a short review can suggest one more. New Memory page (press M), a Memory section in the card sidebar, and a per-project switch. (#30)
- ★ **Welcome tour redesign.** Five pages that also set the basics: interface and AI output language, the Progress model, Progress / Next steps / Ideas for sessions outside Flowly, and the Project memory and Insights switches, with token and cost estimates. After the tour a callout points at the Settings button. (#34)
- ★ **One switch each for Project memory and Insights** across all projects (Settings → AI features). (#34)
- ★ **Progress, Next steps and Ideas in sessions Flowly doesn't manage.** On by default for new users who finish the tour; existing users keep them off until they turn them on (each turn of such a session runs the summary model once). (#34)
- ★ **Several summary models with fallback.** Pick an ordered list in Settings → Models; when one fails, the next is used. (#37)
- ★ **Default permission mode for new sessions**, globally (Settings → Models) or per project. New sessions and Start an agent prefill it. (#40)
- ★ **Azure DevOps connector.** Work items (links or `AB#123`) as read-only card inputs, with search in From… and the Artifacts +. (#50)
- **What's new window.** Existing users see the highlights of a new release once after updating and can page back to earlier releases; reopen it from Settings → General. (#54)
- **Agents can edit, dismiss and remove their card ideas.** (#36)
- **Running cards and sessions show a dot-matrix sweep**, on the board, in the card's session rows and on the session header (nothing drawn with Reduce Motion). (#48, #52, #51)
- **Opening a card centres its lane** beside the sidebar on desktop. (#53)

## Improved

- Memory page has Memory / Archived / Dismissed tabs like Ideas; Ideas and Memory cards share one layout. (#44)
- Queued messages can be taken back into the message box. (#44)
- The overview's In review / Blocked chips scroll the board to that lane. (#44, #53)
- Send behaviour moved to Settings → General; the composer's hint row and mode chooser are gone. (#44)
- One fade-and-collapse motion for Memory, Ideas, Attention and disclosures. (#31)
- The card sidebar shows only the latest Progress; the version list is gone. (#49)
- Faster loading on phones and in compact layouts. (#20, #47)

## Fixed

- Phone freezes when opening a card from Needs attention or from context menus and the project chooser. (#26, #27)
- On phones the transcript rises with the keyboard, and Android scrolling keeps the keyboard open. (#44)
- Next moves fill Paseo's own session view again in long-running desktop apps. (#33)
- Memory review, the Insights digest and Workflow insights run in a dedicated "Flowly background" workspace instead of leaving tabs in a card's workspace, and their temporary sessions are deleted afterwards. (#25, #43, #45)
- Attention badges use Paseo's theme colours; clicked buttons no longer keep a focus ring; opening the board no longer draws a focus ring on the sidebar row. (#29, #41, #44)
- Deleted cards no longer leave session bindings behind. (#24)
- Shortcut help titles are translated. (#22)
- Running sweeps keep their continuity in wide windows and resume cleanly after height transitions. (#55)

## Upgrade

Requires Paseo 0.11.2 or later. Existing project data and settings are preserved. Review the new controls in Settings → Models and Settings → AI features; the release window links to the relevant pages.
