# Flowly 1.7.1

Covers everything merged to `main` since v1.7.0: mostly fixes for the errors the first usage-data reports showed (#69). No *What's new* page: nothing here changes how existing users work.

## Fixed

- **Linux and Windows: Flowly can reach the Paseo daemon again.** Its few direct daemon connections only understood a TCP address; daemons listening on a Unix socket or a Windows named pipe made them fail. That broke clearing Paseo's attention on *Mark as read*, restoring a wrapped-up card's workspace, reusing the background workspace and deleting finished summarizer sessions on those machines. (#69)
- **Windows: session settings and Paseo project create/remove work.** Reasoning, permissions and Stop failed every time because the bundled `paseo.cmd` cannot be started without a shell; Flowly now starts the program it wraps. Creating or removing a native project no longer needs `paseo` on the daemon's `PATH`. (#69)
- A folder path that does not exist and a session image whose file was deleted now show a plain message instead of a system error. (#69)
- Insights' Workflow section says "1 round" instead of "1 rounds". (4476b43)

## Improved

- Several questions from an agent show one at a time under tabs titled by their header; answered tabs carry a check, and ←/→ switch questions on web. The Needs-you form in the card sidebar may grow taller above the session composer. (db1d734)
- Error reports leave out failures outside Flowly's control (the daemon restarting mid-request, every summary model failing), so the reports point at real bugs. (#69)

## Upgrade

Requires Paseo 0.11.2 or later. Existing project data and settings are preserved.
